## 2. Classification legend (design 7 / req 19.4)

- `bounded wire fact/view`: only small bounded fields are needed (IDs, selector string, max-output int,
  session/A-leg/B-leg/trace IDs, model/backend strings, counts, policy revision, part-kind enums).
  A wire lane can supply these as named facts without the payload-scale tree.
- `source/digest contract`: the consumer needs byte-exact source or identity integrity (replay bytes,
  source digest, canonical semantic digest, widening/integrity check, exact counting) rather than the
  materialized tree. A wire lane can satisfy it from the immutable replay source + bounded digests,
  never by retaining a full `Call`.
- `response-only`: the consumer reads response `lipapi.Event`/stream facts only, never request content.
  It stays on the canonical `EventStream` and is wire-safe without any request `Call`.
- `pre-assessment blocker`: the consumer requires the full request content/trajectory (or an unbounded
  content-shaped callback) on the accepted path as currently written. `AssessLargeBody` must decline
  while this authority is occupied/required, unless Tasks 10/12 implement the named wire-native contract.

`nil`/unconfigured optional ports are `bounded wire fact/view` (no-op) for static-disposition purposes;
the `blocker` verdict applies when the port is occupied/required by the frozen generation.
