# Task 20.5 — Remediation Plan Closeout Delta and Final Rollout Evidence

This document records the completion of Phase 7 (Rollout) of the remediation plan (`evidence/remediation-19.3-proof-transient-and-production-assessor-plan.md`), closing out the remaining items from Tasks 19.3, 19.7, 20.3, and 20.4 for GitHub issues #532 and #503.

## 1. Executive Summary

The large-payload streaming fast path remediation addressed two evidence-locked issues identified in the initial certification:
1. **Issue A (Task 19.3 strict heap gate FAILED):** Transient allocation in `CompileProof` scaled proportionally with payload size (~6.5x–7.9x body size: 6.9 MB @1 MiB → 34.1 MB @5 MiB → 165.5 MB @20 MiB) due to `io.ReadAll` and whole-body JSON unmarshaling.
2. **Issue B (Dormant production feature):** `runtime.Executor` implemented `ExecuteLargeBody`, but zero `AssessLargeBody` / `LargeBodyAssessor` composition existed in `runtimebundle` or `stdhttp`. Stock binaries failed `CandidatePrerequisites(spec)` and routed 100% of traffic to canonical execution.

Across Remediation Phases 0–6, both issues were resolved without changing core architectural boundaries:
- **Task 19.3 Strict Gate Flipped from FAIL to PASS:** Replaced `io.ReadAll` with fixed-buffer streaming token scanning and `CallIdentityWriter`, collapsing transient proof-time allocations to **~77–89 KiB flat across 1 MiB, 5 MiB, and 20 MiB** (all well below the 458,752 B/op ceiling).
- **Production Assessor Composed:** Implemented `ProductionLargeBodyAssessor` and `LargeBodyWireExecutor` in `runtimebundle.BuildHost` via `build_large_body_assessor.go`, satisfying `CandidatePrerequisites(spec)` with streaming-only policy formally enforced in production.
- **Per-Lane Outcomes (Task 19.7):** All three protocol lanes (Lane 1: OpenAI Responses, Lane 2: OpenAI Chat, Lane 3: OpenResponses No-Store) satisfy the three mandatory certification conditions and are classified as **ADVERTISE-CAPABLE**.
- **Production Default Preserved:** Configuration strictly defaults to disabled (`server.large_payload_fast_path.enabled: false`), and wire support is **NOT advertised** in default stock binaries.
- **Issue #532 Status:** Explicitly recorded as **stays open** until final downstream PR merge and release.
