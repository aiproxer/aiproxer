## 1. Upstream Foundation Context

PR #631 eliminated duplicate wire parallel execution engines by collapsing the wire execution path onto canonical attempt machinery (`tryOpenParallelGroup` and `openNext`, using internal seams `wireAttemptPayload`, `openWireAttemptTx`, and `WireTakeStream`). This eliminated divergent winner selection logic, restored handicap delay semantics, established independent attempt cancellation, and unified stream lifecycle management.

The `security.session_recorder` port was previously classified as an unconditional blocker in the dependency census. Wire execution exercises the secure session recorder through canonical `retryRecvStream` ownership (`RecordPostHookStreamEvent` and `recordClientFacing`). As proven in PR-1, an occupied session recorder operates identically on wire and canonical streams; it was lifted to `DependencyClassWireSafe`, allowing wire eligibility in secure-session environments.

### 1.3 #632 Authority Propagation
PR #632 connected the generation-pinned authority evaluation directly to the production bundle composition root (`ProductionLargeBodyAssessor`, `AuthorityGate`, and `wireProofGate`). All static and dynamic blockers compiled from the generation census are propagated without loss to candidate-path gates.

### 1.4 PR-1 Hygiene
PR-1 established strict internal encapsulation: zero leaky abstractions, compile-time type boundaries between core orchestration and transport/plugins, and absence of circular package dependencies.

## 2. PR-2 Implementation Decisions and Contracts

### 2.1 Item 1: Publication-Closed Sentinel (`errPublicationClosed`)
- **Problem:** Five call sites across four files in `internal/core/runtime` emitted ad-hoc `errors.New("publication closed")` (plus variant `"continuation publication closed"`), while `attempt_session.go:1281, 1337` classified them using substring matching `strings.Contains(err.Error(), "publication closed")`. Substring matching is fragile and susceptible to false-positive classification from wrapped external errors.
- **Solution:**
  - Defined unexported package sentinel `var errPublicationClosed = errors.New("publication closed")` in `internal/core/runtime/attempt_session.go`.
  - All producer sites wrap the sentinel using `%w`. Classification moved from substring
    matching to `errors.Is`; only `errors.Is` consumers of these errors exist repo-wide,
    so the added context prefixes are unobservable to classifiers (log strings changed):
    - `executor_assemble_stream.go:112`: `fmt.Errorf("runtime: %w", errPublicationClosed)`
    - `executor_recv_loop.go:533`: `fmt.Errorf("recv loop replacement: %w", errPublicationClosed)`
    - `interleaved_open.go:182`: `fmt.Errorf("interleaved open: %w", errPublicationClosed)`
    - `turn_terminal.go:744`: `fmt.Errorf("turn terminal: %w", errPublicationClosed)`
    - `terminal_decision_continuation.go:161`: `fmt.Errorf("continuation %w", errPublicationClosed)`
      (renders byte-identically to the old `"continuation publication closed"` diagnostic string)
  - Consumer classification in `attempt_session.go:1283, 1339` matches exclusively via `errors.Is(err, errPublicationClosed)`.
  - Repo-wide search confirmed zero external packages rely on the `"publication closed"` error substring.
- **Verification:**
  - `TestPublicationClosedSentinel_ErrorsIs`: validates `errors.Is` traverses the wrap chain for all five producer sites.
  - `TestPublicationClosedSentinel_ReadyDispose_WrappedSentinel`: verifies cleanup occurs on wrapped sentinel errors.
  - `TestPublicationClosedSentinel_ReadyDispose_DecoyStringNotSwallowed`: proves decoy errors containing substring `"publication closed"` or matching exact string without the sentinel instance are NOT classified or swallowed.

### 2.2 Item 2: Billing Parity
- **Problem (a):** `WireTurnFacts.ToReceiveView/ToTerminalFacts` in `internal/core/largebody/conservative_dependencies.go:300, 334` derived `IdentityStamped` as `PricingRef != "" || ChargePolicyRef != ""`. This diverged from runtime billing admission in `billing_admission.go:264-269`, which requires a resolved non-empty `AccountID`.
- **Resolution (a):** Aligned `conservative_dependencies.go` to the canonical derivation: `IdentityStamped: strings.TrimSpace(f.Economic.AccountID) != ""`. Pricing and policy refs do not constitute financial identity for settlement.
- **Problem (b):** `AuthorizeWireBilling` with nil `BillingExposureAdmission` returned empty exposure without fallback identity (`billing_admission.go:287-289`), differing from canonical `stampExposureIdentity`.
- **Resolution (b):** Fenced with explicit documentation and tests. On stock distributions without enterprise billing, exposure admission is nil by design; returning empty exposure safely skips operational exposure limits while preserving bounded non-money execution. Custom billing callbacks (`HasCustomCallCallbacks`) fail closed to canonical before commit.
- **Verification:**
  - `TestTask12_3_IdentityStamped_ParityWithCanonical` (5/5 table cases): confirms stamping occurs if and only if `AccountID != ""`.
  - `TestWireBilling_CheckCheapCredit_Parity`, `TestWireBilling_AuthorizeExposure_Parity`, `TestWireBilling_AuthorizeExposure_NilAdmission_CanonicalParity`, `TestWireBilling_CustomBillingIdentity_DeclinesToCanonical`: confirm credit and exposure parity across nil and populated billing configurations.

### 2.3 Item 3: Stock-Host Reachability & Authority Port Refinements
- **Problem:** In stock hosts, `featurehost/process.go:90, 119-126` unconditionally constructs `compactionDetector` and `conversationStore`. `build_large_body_assessor.go` mapped these non-nil references directly to `ConversationViewReaderOccupied`, `ConversationViewTaggerOccupied`, `SteeringWriterFactoryOccupied`, and `CompactionDetectorOccupied`. Consequently, every stock host evaluated to 100% wire-ineligible (`HasStaticBlocker() == true`).
- **Differential Proofs & Minimal Safe Wire Contracts:**
  - **Conversation View Reader (`ConversationViewReaderOccupied` & `ConversationReaderFreshALegSupported`):** `TestStockHost_BehavioralDifferential_ConversationViewReader` proves that under a clean stock baseline (empty `NeverBackend` tags), `snapshotAndProject` takes the fast path and returns the request `Call` unmodified (identity no-op), identical to wire execution. When mutating tags exist, canonical filters turns, proving the reader must block when mutating feature planes are active or when historical tags exist. Refined contract: `ConversationViewReaderOccupied = in.In.ConversationReader != nil`, and `ConversationReaderFreshALegSupported = in.In.ConversationReader != nil && in.In.ConversationReaderStockOrigin`. Stock origin is strictly certified and validated at the composition boundary (`resolveCandidateConvReader`), ensuring forged origin assertions on custom readers are overwritten to `false`. Under this contract, fresh A-leg turns with certified stock origin are accepted, while custom readers or non-empty historical states safely decline.
  - **Conversation View Tagger (`ConversationViewTaggerOccupied`):** `TestStockHost_BehavioralDifferential_ConversationViewTagger` proves `TagNeverBackend` is called 0 times in both canonical and wire execution when `local_turn_handlers` is absent. Refined contract: `ConversationViewTaggerOccupied = in.In.ConversationStore != nil && hasLocalTurn`.
  - **Steering Writer Factory (`SteeringWriterFactoryOccupied`):** `TestStockHost_BehavioralDifferential_SteeringWriterFactory` proves steering writers are called 0 times when neither interleaving nor terminal decision provider is active. Refined contract: `SteeringWriterFactoryOccupied = in.In.ConversationStore != nil && hasSteeringPlanes`.
  - **Compaction Detector (`CompactionDetectorOccupied`):** `TestStockHost_BehavioralDifferential_CompactionDetector` proves that without `compaction_observers` or `compaction_preservers`:
    1. Request-side: zero events dispatched (`RequestOpened` returns nil).
    2. Response-side: `PreviewResponse` and `ResponseReleased` are invoked on released stream events identically for both canonical and wire streams.
    Refined contract: `CompactionDetectorOccupied = in.In.CompactionDetector != nil && hasCompactionPlanes`.
  - **Audit of Remaining Ports:**
    - `ExposureAdmissionOccupied`: false on stock host (`in.Prod.BillingExposureAdmission == nil`); blocks wire when active.
    - `PreflightEnabled`: false on stock host (`in.AccountingRT.Preflight == nil`); blocks wire when active unless exact wire counter present.
    - `StreamUsageOccupied`: false on stock host (`in.AccountingRT.StreamUsage == nil`); blocks wire when active.
    - `AdminCountServiceOccupied`: false on stock host (`in.AccountingRT.AdminCountService == nil`); blocks wire when active.
    - `CapsResolverOccupied`: stays a documented blocker when backends exist that require capability resolution, as `capabilities.Resolver.DescribeCandidate` takes full attempt `Call`.
- **Verification:**
  - `TestStockHost_StockComposedCensus_Accept`: stock-composed census with refined contracts evaluates to `AssessmentDecisionAccept`.
  - `TestStockHost_Audit_PortsDeclineWhenActive` (6/6 subtests): proves each audited port/plane safely blocks wire execution when active.
  - `TestStockHost_BuildHost_WithFastPath_StockComposed_Reachability`: verifies `BuildHost` sets all 4 root-cause ports and all 4 audited ports to false.

### 2.4 Item 4: Wire×Interleaved Composition Policy
- **Decision:** Decline wire execution when interleaving is enabled. Interleaving involves multi-stage prompt generation, thinker/executor coordination, and synthetic continuation frames requiring full intermediate `Call` materialization.
- **Enforcement:**
  - Eligibility gates: `AssessLargeBody` declines with `DeclineReasonAuthorityBlocker` when `e.interleavedEnabled()` is true. `LargeBodyStaticDisposition` reports `StaticWireDispositionDefinitelyCanonical` with `StaticWireReasonStaticBlocker`.
  - Defense-in-depth in stream assembler (`executor_assemble_stream.go:75, 82`): wire attempts unconditionally bypass `getOrBeginInterleavedTurn` and interleaved continuation wrappers.
  - Fact preservation in `executor_prepare_request.go:91, 105`: the facts-rebuild branch preserves `wirePayload` across `newRecvTurnFacts`, so `isWire` cannot flip false mid-request (safe for non-wire: the saved value is nil there, making the restore a no-op).
- **Verification:**
  - `TestWireInterleaved_DeclinesWhenInterleavedEnabled`: verifies static disposition is definitely canonical, `AssessLargeBody` declines, and wire route is not attempted.
  - `TestAssembleExecutorStream_WrapperSelection/wire_payload_skips_interleaved_wrapper`: confirms stream assembler skips interleaved turn wrappers on wire attempts.

## 4. Known Residual Boundaries (stated scope limits, not regressions)

- **Latent NeverBackend write path:** `nonforwardable.Registrar` (`internal/infra/conversationview/sdkadapter/registrar.go:57`) is an SDK contract that can write NeverBackend tags with no feature-plane gate. It has zero production consumers today, so the `local_turn_handlers` refinement is sound now; any future consumer bypasses it. Mitigation: archtest ratchet or steering note when a consumer lands.
- **Store-error availability divergence:** canonical `snapshotAndProject` fails closed on store read error; the wire path performs no read and proceeds. Availability-only divergence, not a semantics divergence; acceptable while the reader contract is read-only-on-clean-baseline.
- **Minor test gaps (non-blocking):** no decline-pinning test binds `hasSteeringPlanes` refinement to `SteeringWriterFactoryOccupied` (the plane loop independently declines those planes, so behavior is safe); no behavioral test pins the `ensureRecvTurnFacts` wirePayload-rebuild case (defensive-only, unreachable in prod today).
